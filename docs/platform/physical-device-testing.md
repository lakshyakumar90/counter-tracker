# Physical Device Testing

Pace is tested on physical Android phones. Do not create or install emulator system images for this project.

## Device matrix and status

The roadmap requires two physical phones, including one from a manufacturer with restrictive background battery management. The owner has not recorded the available device models in this repository yet, so device coverage remains pending; do not treat a build or test APK as a device test.

## Weekly field routine

Once recording exists, perform and record one 30-minute outdoor session each week on both devices in rotation. Cover screen-on and screen-off operation, pause/resume, location permission changes, battery use, app interruption/recovery, and offline behavior as supported by the current phase.

Record the date, device and Android version, app build, activity type, approximate duration, battery start/end, permission state, screen-off interval, interruption/recovery result, and defects. Do not commit precise routes, raw GPS samples, account identifiers, or other personal workout data. Store sensitive evidence locally and summarize only non-identifying results here.
