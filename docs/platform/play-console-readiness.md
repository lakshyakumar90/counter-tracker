# Play Console Readiness

This repository does not contain a Play Console account credential or account verification record. The project owner must complete the account-dependent steps; never commit passwords, identity documents, payment details, or recovery codes here.

## Owner checklist

- [ ] Create or select the owner-controlled Google Play Console developer account.
- [ ] Complete Google identity and developer verification in Play Console.
- [ ] Record whether the account is personal or organization-owned in a private project record.
- [ ] If it is a personal account created after November 13, 2023, plan for Google's required closed test with at least 12 opted-in testers for 14 continuous days before requesting production access.
- [ ] Confirm the app listing owner, launch countries/locales, privacy policy, data safety answers, and support contact before release.
- [ ] Create and securely back up the upload key; keep it and passwords outside Git.

**Status:** not verified in this repository. The account type and any applicable testing timeline remain owner-confirmation items.

Check the current requirements in [Play Console Help: Target API level requirements](https://support.google.com/googleplay/android-developer/answer/11926878) and [Play Console Help: Test your app](https://support.google.com/googleplay/android-developer/answer/9845334) before planning a release.
